# Crime Rate Predictor

### A simple Crime Rate Predictor App.

## Tech Stack
- HTML/CSS
- Python & Javascript

## Dataset:
### Crime Dataset India ( Kaggle )

## Libraries:
- Pandas : Data Manipulation.
- Numpy : Data Manipulation & Processing
- Scikit-Learn : Model Evalutaion
- Xgboost : Model Training
- Geopy : Coordinates of Cities
- Folium : Interactive Map
- Plotly : Interactive Plots
- Flask : Backend
- Flask-Caching : Caching Elements(Map, Plots)
